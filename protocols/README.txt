Lab protocols for the cell culture log web page

1. Put protocol files in this folder (PDF, Word .docx, or photos).
2. Ask Claude Code to "update the site protocols". Claude reads the new files and
   writes their steps, cell line and seeding numbers into protocols.json.
3. Upload the cell-log-site folder to GitHub again.

Everyone's Protocols tab picks up the changes the next time they open the page.
The files themselves stay here too, so people can open the original from the app.
Use names without spaces (underscores or hyphens), e.g. hTERT-RPE1_passaging.pdf.
